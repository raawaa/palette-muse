---

## 1. 产品概述

Palette Muse 是一款**色彩灵感收集 App**。用户以一张穿搭自拍为起点，提取穿搭主色作为「色彩主题」，随后在日常生活中随时捕捉与该色系相近的场景，照片自动归入对应色系主题。每个色系主题长成一组「穿搭照 + 同色系生活捕捉」，最终导出为统一调性的合成海报，分享到小红书等社交平台。

**核心叙事**：穿在身上的颜色，去生活里找它的回响。

---

## 2. 目标用户

在小红书等社交平台分享穿搭与生活的女性用户。追求审美与调性，喜欢用色彩讲故事；行为特点是「随手拍、碎片化捕捉」，抗拒多余的操作负担。

---

## 3. 核心使用流程

1. 拍一张**穿搭自拍** → 自动提取主色 → 创建色系主题（首次）/ 归入已有同色系主题
2. 日常生活中随时拍**生活场景** → 自动分析主色 → 归入色系最匹配的主题（拍完轻确认）
3. 主题逐渐积累成一组同色系照片
4. 进入主题 → 导出 → 生成统一调性合成海报 → 分享小红书

---

## 4. 设计调性（Aura Aesthetic）

详见 `DESIGN.md`，关键点：

- **品牌个性**：Effortlessly Chic
- **美学**：Minimalism + Glassmorphism，大量留白
- **主色** Rose Gold `#B76E79` · **辅色** Soft Lavender `#E6E6FA` · **背景** Pearl White `#FDFBF7` · **正文** Ink `#1A1A1A`
- **字体**：Playfair Display（标题）+ Plus Jakarta Sans（功能性 UI）
- **圆角**：超软 Pill（24–32dp）
- **层级**：玻璃质感（`blur(20px)` + 半透明白）+ 极软环境阴影（**禁用黑色阴影**，用主色 5–8% 透明度）
- **色彩哲学**：UI 应「消失」，让用户照片成为主角

## 6. 屏幕设计需求（基于 Stitch 设计稿）

### 6.1 首页 HomeScreen
- **TopAppBar**：品牌名 PALETTE MUSE（玻璃质感）；MVP **去掉 search 按钮**，保留菜单/设置入口
- **Hero**：「探索你的色彩」——文案构建时调贴合「色彩灵感收集 / 色系主题」
- **色系主题列表**：大图杂志卡（全图 + 底部渐变信息条：代表色色点 + 主题名 +「N 捕捉 • 更新时间」+ 跳转圆钮）
- **空状态卡**：「开启新收藏 / 拍下你的穿搭，创建首个色彩主题」
- **底部导航**：工作室 + 我的 + 中间 FAB（`add_a_photo`，渐变凸起）

### 6.2 相机 CaptureScreen
- 全屏取景器 + 暗角聚焦
- **顶部**：close + TARGET 指示（当前最匹配的主题色，如「陶土红」）+ flash
- **中心**：十字准星 + Match 徽章（实时匹配度，如「92% Match」，pulse 动画）+「对准物体以提取色彩」
- **已捕捉预览条**：水平滚动缩略图 + 匹配度角标（88% / 94%）
- **快门按钮**：大圆形带按压动画 —— ⚠️ **构建时必须接 `onClick` → `capturePhoto()`**（现有代码这里是死代码，主链路断点）
- **拍完过渡（设计稿未覆盖，构建时自建）**：底部弹出轻量确认条「归入【XX 主题】？〔确认〕〔另起新主题〕」
- **MVP 精简**：砍掉 `auto_awesome`（灵感画廊）、`add_photo_alternate`（相册选图）；`tune` 保留做翻转相机等基础功能

### 6.3 主题详情 ThemeDetailScreen
- **顶部**：返回 + 品牌 + `more_horiz`（主题设置：改色 / 重命名 / 合并拆分 / 删除）
- **主题头部**：**色板**（3 个色点）+ 主题名 +「N 次捕捉 • 更新时间」
- **主题起点 Hero**：穿搭照大图置顶（h-530）+ 左上角「主题起点」玻璃标签（star）
- **捕捉照瀑布流**：masonry 2 列
- **导出 FAB**：右下角玻璃 pill「导出海报」
- **MVP 精简**：不要 Origin 文案、不要捕捉标签（细节 / 配饰…）

### 6.4 导出 ExportScreen（合成海报）
- **海报预览**：3:4 竖版合成海报（Bento 2×2 拼贴 + 标题 + 色板 tag），复用现有 `PosterRenderer`
- **统一调性**：每张图套一层主题色调（设计稿用 `mix-blend-multiply` + primary overlay）
- **模板选择**：网格 / 胶片 / 日记 / 极简 —— **MVP 先做 1 个（网格）**
- **底部操作**：分享到小红书（主）+ 保存到相册（次）
- **海报标题**：MVP 用主题名

### 6.5 空状态 / 冷启动
- 无任何主题时：「拍一张你的穿搭，开启第一个色彩主题」+ 醒目拍照入口

## 7. 关键交互规则

- **取色全自动**：聚焦主体区域，排除背景与肤色；不打扰用户
- **色系判定细粒度**：色相 + 明度 + 饱和度都接近才算同色系
- **归并交互**：拍完弹轻量确认（归入最匹配主题 / 另起新主题）；取色全自动
- **主题绑定色系**（非单件穿搭），长期生长、跨时间积累
- **事后可改**：主题色可修改 → 该主题自动重新归类
- **穿搭 / 生活不强制区分**（路线 A）：只看主色和归类；未来预留人像检测扩展点
- **主题色系 = 代表色 + 色板**：代表色用于首页卡片 + 归类基准；色板（3–5 色）用于详情页 / 导出展示，从该主题照片主色聚类生成

## 8. 已确认的设计决策

1. **冷启动** — 第一张照片引导为穿搭照
2. **穿搭 / 生活不区分**（路线 A）— 靠引导实现「穿搭为起点」，不靠技术强制；未来预留人像检测
3. **导出形式** — **合成海报**（3:4 拼贴 + 标题 + 色板），非多图直发九宫格；复用现有 `PosterRenderer`
4. **底部导航** — 2 tab（工作室 / 我的）+ 突出 FAB 拍照入口
5. **主题命名** — 自动语义名（如「Dusty Rose」）+ 用户可重命名
6. **主题色系** — **色板**（代表色 + 色板），非单色
7. **拍完归类确认** — 构建时自建底部轻量确认条（设计稿未覆盖）
8. **MVP 精简范围** — 砍：首页 search、相机辅助按钮（auto_awesome / add）、详情 Origin 文案与捕捉标签、导出多模板（先做网格）
